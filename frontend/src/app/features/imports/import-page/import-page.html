Importación y exportación

Carga masiva de operarios y talleres desde Excel o CSV. Cada archivo se procesa por lotes: las filas válidas se guardan y las rechazadas se reportan con su número de fila y el motivo, sin dejar datos a medias.

info
Cómo exportar. Los listados de usuarios, talleres e inscripciones tienen su botón «Exportar», que genera un .xlsx o .csv con las mismas filas y filtros que se ven en pantalla.
